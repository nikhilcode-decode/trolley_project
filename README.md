# Django Celery RabbitMQ Project

This is a Django-based web application that uses **Celery** with **RabbitMQ** to handle asynchronous tasks, such as sending automated welcome emails to users.

## Features

- User registration and management
- Asynchronous task processing using Celery
- RabbitMQ as the message broker
- Sends welcome emails automatically

## Technologies

- Django 5.2
- Celery 5.5
- RabbitMQ
- SQLite (default DB, can be switched)
